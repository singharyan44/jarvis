# Phase 1 — Improve Voice Pipeline

## Current

```text
Double clap
    ↓
Record fixed duration
    ↓
Whisper
```

## Target

```text
Double clap
    ↓
Listen until silence
    ↓
Stop recording
    ↓
Whisper
```

Benefits:

- Natural speech length
- No cut-off commands
- Better assistant experience

---

# Phase 2 — Speech Cleanup Layer

Create:

```text
cleanup/

└── cleaner.py
```

Purpose:

Convert raw STT output into cleaner text.

Example:

Input:

```text
uh hey jarvis can you like open spotify please
```

Output:

```text
Hey Jarvis, can you open Spotify please?
```

Handles:

- filler word removal
- punctuation
- capitalization
- obvious STT mistakes

Does not:

- change meaning
- rewrite personality
- force formal tone

# Phase 3 — Skill-Based Command System

Replace:

```python
if "open spotify" in text:
```

With:

```text
User text

↓


Command Router

↓


Skill

↓


Action
```

Example:

```text
commands/

spotify.py
browser.py
system.py
cursor.py
```

Goal:

New abilities can be added without modifying the core assistant.

# Phase 5 — AI Intent Layer

Pipeline:

```text
Speech-to-Text

↓


Cleanup

↓


AI Intent Model

↓


Structured Output

↓


Validator

↓


Execute
```

AI responsibilities:

- understand user meaning
- decide intent
- select tool/action
- format response

Example:

User:

```text
put on some music
```

AI:

```json
{
  "intent": "command",
  "tool": "spotify",
  "action": "play",
  "response": "Playing music."
}
```

---

# Phase 6 — Validation Layer

Create:

```text
validator.py
```

Purpose:

AI output should never directly execute.

Checks:

- tool exists
- action exists
- parameters are valid
- confirmation required

Example:

AI:

```json
{
  "action": "shutdown"
}
```

Validator:

```text
Requires confirmation
```

# Phase 8 — Offline Mode

Online:

```text
faster-whisper

↓


AI formatting

↓


Cloud TTS

↓


Response
```

Offline:

```text
faster-whisper / Vosk

↓


Rule cleanup

↓


Local commands

↓


Coqui / pyttsx3

↓


Response
```

Disabled offline:

- OpenRouter
- cloud TTS
- external AI formatting

# Phase 9 — Memory System

# Phase 10 — Context Management

Problem:

LLM context windows are limited.

Solution:

```text

↓


Context Manager

↓


Relevant memory

↓


AI
```

# Core Design Principles

- Local first
- AI optional
- Modular architecture
- Replaceable components
- Offline capable
- No single point of failure

The goal is not a giant AI script.

The goal is a modular assistant framework that can expand with new capabilities over time.
